About the Project

BookNest is a web-based academic project developed using Python and Flask. It combines book data collection, data processing, web development, and content-based recommendation techniques. Its purpose is to make book discovery easier and more organized.

Recommendation Approach

TF-IDF + Cosine Similarity

BookNest represents book titles and categories as numerical vectors using TF-IDF. Cosine similarity compares these vectors to identify books with similar features. Category information receives additional weight in the comparison.
